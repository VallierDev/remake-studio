YouArt Desktop 爆款复刻怎么用

先在 YouArt 桌面端首页点击「爆款复刻」，再加入参考视频与商品图。

  1. 点击「爆款复刻」

    打开 YouArt Desktop 首页，点击输入框下方的「爆款复刻」。输入框会显示 Viral Remake 标签。

  2. 加入参考片和商品图

    粘贴从找片工具复制的 TikTok 链接，添加自己的商品图。若链接导入失败，可以上传已下载的 MP4 原片。

  3. 说明想怎么改

    写清楚要保留的镜头节奏、要替换的商品和场景，检查模型与积分报价后生成。
